# IT1214-Student-Grade-System
This is a Java-based console application designed for teachers to manage student academic records efficiently. 

### Key Features:
- Add new student records (ID, Name, Marks).
- Display all student details.
- Search for a specific student by ID.
- Calculate the average marks of all students.

### How to Run:
1. Compile the files: `javac Student.java StudentGradeSystem.java`
2. Run the application: `java StudentGradeSystem`
